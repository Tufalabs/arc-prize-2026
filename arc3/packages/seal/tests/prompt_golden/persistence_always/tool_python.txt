Run one game-scoped Python snippet against preloaded game state. Available globals: `history` (this level's Turns), `available_actions`, and `submit_action(actions)` for executing one or more real environment actions, each an `Action`. Frames expose `.grid`, `.diff_sparse` and `.color_counts`; `segment(frame.grid)` gives their objects. For the latest before/after diff, read `history[-1].frame.diff_sparse`. A MOUSE action is `Action('MOUSE', row=r, col=c)`, with integer `row` and `col`. Colors are indices 0-15. Use `segment(...)` as the primary view and `ascii_grid(...)` only for a small specific region. Use `print(...)` for compact output; a trailing expression is echoed like a notebook cell. `test_world_model()` tests your `world_model.py` against `history`; while it passes, `submit_action` checks each action as it runs.
