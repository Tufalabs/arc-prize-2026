## The game

Pathfinder is not an official ARC-AGI-3 game, but a simple test game we wrote. It has five levels, each a fixed maze with one start and one goal. Four actions move the green player one cell through the white corridors, black walls block it, and reaching the red goal clears the level. The mazes grow from 4 to 32 cells a side, drawn on the same 64×64 frame. Each level's baseline is its shortest path.

The model is told none of this. It gets the same prompts as for any game, and sees each level only once it gets there. These are the frames the levels open on:

=== epilogue
The model won level 1 by trying the actions directly, with two of its four having no effect. It wrote its world model after reaching level 2. There, the harness's check stopped its first batch after one move, because the world model drew the next frame wrong, and the model fixed that. The harness's search then gave it the shortest path. On levels 3 to 5 the model reused the same world model unchanged, and played each level in one batch from that search.

{{result}}

Each level scores (baseline actions / actions taken)² × 100, capped at 115, and the game score weights the levels by their number. The game took 32 model responses and 24,563 generated tokens. Its context stayed under the limit throughout, so the harness never compacted it.
